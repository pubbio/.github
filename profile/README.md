# Pubb

**Realtime infrastructure for connected apps.**

Pubb helps you build notifications, chat, live dashboards, and collaborative experiences with WebSockets, channels, and a simple HTTP API.

- **Publish and subscribe** — send events from your backend to connected clients.
- **Control access** — use public channels or authenticate subscribers with private channels.
- **Track presence** — see who's online and respond when members join or leave.
